# Circuit outline provenance

Outlines are simplified vector centerlines traced from the references below, not AI-generated geometry. `src/track-map-data.json` retains each outline’s title, source URL, reference image/PDF, scope and configuration notes. The tray displays the credit next to the selected map. CW and CCW entries share a physical outline; direction remains part of the layout label and stable ID. Maps are illustrative, not navigation or safety diagrams.

The catalog contains 52 layout/direction IDs; 51 have a credited trace or clearly marked venue reference. An unverified configuration shows a placeholder and source link. Staff can supply the correct credited trace through the editor later. Archiving and hiding only change availability, never lap IDs or results. Circuit renames update all sibling labels while preserving circuit identity.
