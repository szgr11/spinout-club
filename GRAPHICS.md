# Graphics and language

Use graphics for identity, recorded data or a real object. Do not use invented circuit maps, fictitious telemetry or a generic car to represent a member's vehicle.

The driver-profile helmet is traced from the shell, visor, chin bar and hardware in Bell's GP3 Sport manufacturer photograph. Brand marks are omitted; it is a driver identity illustration, not a claim about the member's equipment:
https://www.us.bellracing.com/wp-content/uploads/sites/13/2024/07/GP3-SPORT-WHITE-1024x1024.jpg
Product reference: https://www.us.bellracing.com/p/gp3-sport/

The garage displays the actual selected vehicle, horsepower and tire records. It does not imply that a generic illustration is the member's car. Profile totals describe logged laps, circuit layouts, vehicles and track days, not race finishes. A lap-history graphic is shown only when at least two logged laps share a driver, vehicle, layout and lap type; it uses up to 20 chronological records, and does not imply a fixed setup across dates.

Navigation is shared by calendar and member pages. Page headings use the shared ClubHero component. Dark surfaces specify light text; dark text is reserved for light or yellow fills.

All product text uses the single `--font-club` font definition, including headings, native form controls and dialog content. Keep product copy factual; page headings do not need motivational taglines. UI panels and controls use square corners.
